# Proposal

## Why

Экран вождения сегодня — две раскладки (HUD с кадром и «классическая» без него), которые выбирает машинка по `video.enabled`, поверх двух схем управления (аркада / танк), которые выбирает пользователь. Органы стоят по-разному: джойстики то на кромках кадра, то по углам; кнопка трюков то в боковой полосе, то снизу по центру; предупреждения то под верхним рядом, то под трюками. Водитель, включив или выключив видео, переучивает руки; в коде это две ветки одного экрана с дублированными органами и два набора мест. Нужна одна раскладка: органы не двигаются, меняется только содержимое окна.

## What Changes

- **Одна раскладка на всё.** Классическая раскладка убирается. Экран вождения всегда — окно 16:9 во всю высоту с органами по его кромкам (нынешний HUD). Выключатель видео на машинке решает только, живо ли окно: `enabled: true` — в нём кадр и подписка `view`; `false` или домен не прочитан — окно пустое (фон, без плашки «Нет картинки»), `view` не уходят. Ни один орган не меняет места.
- **Верхний бар из трёх кнопок.** Кнопка трюков уходит из боковой полосы в верхний ряд: справа над окном, рядом с переключателем схемы, — одна капсула из трёх сегментов **трюки / видео / настройки**. Три состояния кнопки трюков (✦ / ✕ / ⏹ с кольцом хода) сохраняются в форме сегмента; карточка трюков раскрывается вниз, под сегмент.
- **Аркада — левое место пустое.** В аркаде один джойстик справа на кромке окна; место левого остаётся свободным и занимается вторым джойстиком в танке. Зеркального дубля и «кочующих» органов нет.
- **Правило режима без режима.** `DriveModeRule` перестаёт выдавать раскладку (`DriveMode` убирается) и решает только подписку и приём ввода — как прежде, по домену `video` и накрытию экрана.
- `DriveLayout` теряет точку `tricks` (трюки — в верхнем ряду, чьё место уже задано); остальные точки не меняются.
- Кадр галереи «Drive classic (video off)» становится «Drive video off» — та же раскладка с пустым окном.

Провод не меняется: ни `docs/protocol.md`, ни `contract/*.json`, ни прошивка.

### Modified Capabilities

- `app/drive-hud`: «Две раскладки экрана вождения — по выключателю видео на машинке» переименовывается в «Одна раскладка экрана вождения; выключатель видео — на машинке» и переписывается: выключатель решает, живо ли окно, а не раскладку; «Кадр — окно 16:9…» — окно есть всегда, не только «в HUD»; «Раскладка выводится из экрана и safe area…» — трюки в верхнем ряду, точки `tricks` нет, карточка вниз; «Приборы показывают связь и намерение пульта» — справа переключатель схемы и бар из трёх; «„Нет картинки“ — поверх последнего кадра…» — плашка только при включённом видео, при выключенном окно пустое; добавляется «Бар из трёх кнопок — трюки, видео, настройки».
- `app/drive-session`: «Режим экрана вождения и подписка решаются вместе» — правило решает подписку и ввод, раскладка одна; сценарий «Домен ещё не прочитан» — окно пустое, `view` не уходят.

Спека `app/tricks` («Одна кнопка — три состояния») не меняется: состояния и кольцо хода те же, меняется только место и форма кнопки, что описано в `app/drive-hud`. `app/screens-and-theme` не меняется: переключатель схемы и галерея — как были.

## Impact

- `app/AJMiddleCar/DriveView.swift` — ветка `classic` и её органы удаляются; одна `body` с окном; верхний ряд — переключатель схемы + бар.
- `app/AJMiddleCar/DriveMode.swift` + `app/tests/drivemode` — `DriveMode` убирается, `DriveScreenState` = `{watching, inputAllowed}`; правило кнопки видео (`videoTap`) без изменений.
- `app/AJMiddleCar/DriveLayout.swift` + `app/tests/drivelayout` — точка `tricks` удаляется; проверка её координат — тоже.
- `app/AJMiddleCar/TricksControl.swift` — форма сегмента бара вместо FAB 46 pt; `CardEdge` убирается, карточка раскрывается вниз; API родителя (`running`, `startedAt`, `onSelect`, `onStop`, `debugOpen`) сохраняется.
- Новый `app/AJMiddleCar/ControlBar.swift` — капсула из трёх сегментов.
- `app/AJMiddleCar/GalleryView.swift` — подпись кадра «Drive video off».
- `CLAUDE.md` — абзац «The drive screen is a HUD…» — одна раскладка, бар, ссылка на `openspec/specs/app/drive-hud` вместо `docs/superpowers/specs/2026-09-15-drive-hud-design.md`.
- Прошивка, мок, контракт, протокол — не затрагиваются; `tools/test-all.sh` закрывает хост-тесты `drivelayout`/`drivemode` и сборку.
