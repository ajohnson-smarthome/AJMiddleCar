# Proposal

## Why

Путешествие J8 (`ajm-64-logic-review`, `review/08-mock-blind-spots.md`) прошло каждую спеку `car/*` против мока и трёх conformance-прогонов и нашло, где мок изображает не машинку: «перезагрузка» глушит только UDP, `/ota` берёт образ любой платы, валидатор `/config` падает на `NaN`, `build` из версии с git-суффиксом — `-1`, клип 4:3 при проводе 16:9, ни одной деградации железа, и три прогона молчат про сторожевой таймер, конец видеопотока и формы REST. Пока это так, симулятор учит пульт тому, чего машинка не делает, а conformance против машинки падает там, где мок проходил (`AJM-108`). Плюс `AJM-86` — разовый `Connection refused` от HTTP мока при живом видео, пойманный двумя воркерами.

Четвёртый change эпика `AJM-64`, параллельно с `ajm-64-review-fixes`. Все файлы — `tools/`; стенда не требует ни один пункт.

## What Changes

- **Мок ведёт себя как машинка**: пауза перезагрузки — и для REST (`AJM-103`); `/ota` проверяет заголовок образа целиком — `chip_id` и магическое слово дескриптора (`AJM-105`); лимиты тела REST и `bad_json` на тело-не-объект (`AJM-113`); `build` — цифры после первого `+` (`AJM-108`); клип 1280×720 (`AJM-110`).
- **Мок умеет деградацию** флагами, все выключены по умолчанию: `--bus down`, `--camera off`, `--radio mismatch|unavailable`, `--reset-at-boot`, `--write-fail <domain>`, `--wifi failed` для адаптера, если он в моке появится, — нет, только машинка (`AJM-116`, решение пользователя 2026-09-19).
- **Валидатор из генератора** не падает на `1e400`/`NaN`/`Infinity` и хранит `1e2` для `int` целым (`AJM-111`).
- **Constants mirrored by hand** проверяются тестом против прошивки (`AJM-121`).
- **Три прогона получают недостающие легенды**: RT — сторож, возврат, простой сессии, повтор `hello` (`AJM-117`); видео — чужой sid, `/status.video` посреди потока, `bye`, вытеснение, струйка (`AJM-118`); REST — домен не объект, `proto` в теле, формы `wheels[i]`, второй `spin`, `reverse`, `rx_hz` без потока (`AJM-119`).
- **Flaky** `AJM-86`: `test-all.sh` сохраняет лог мока при падении; попытка воспроизвести циклом; не воспроизвёлся — Canceled с записью.
- Поведение машинки, адаптера и пульта не меняется.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `shared/mock-and-conformance`: честный список отклонений мока сокращается, флаги деградации, легенды трёх прогонов, тест зеркал.

## Impact

- `tools/mock_car/*`, `tools/conformance*.py`, `tools/gen_contract.py` (эмиттер валидатора) и `tools/test_gen_contract.py`, `tools/test-all.sh`, `tools/mock_car/sample.h264` (перегенерация ≤ 400 КБ), README мока.
- Прошивка и приложение — не трогаются. Контракт — не трогается.
- Три пункта `ajm-64-review-fixes` (1.2, 3.1, 3.4) используют флаги деградации в проверке; до их появления там — хост-тесты.
