# Spec Delta

## MODIFIED Requirements

### Requirement: Подписка смертна — по тайм-ауту, с концом сессии и по выключателю
Подписка SHALL завершаться, когда с последнего принятого `view` прошло строго больше `video.subscribe_timeout_ms`; когда у сессии `car/rt-link` не осталось владельца (`bye`, простой); когда владелец сессии сменился (вытеснение другим `hello`); когда `video.enabled` выключен. Три последних SHALL срабатывать на ближайшем такте канала, а не по тайм-ауту (граница такта — `contract.config.domains.video` → `enabled`). С концом подписки кодер SHALL закрываться, пайплайн — останавливаться, `video.state` — становиться `idle`, `fps` и `kbps` — нулями; ни одного чанка прежнему адресату после смены владельца SHALL NOT уходить. Новый владелец открывает поток своим первым `view` как любой первый подписчик — с чистого листа (`Каждый старт потока — с чистого листа`).

#### Scenario: bye посреди просмотра
- **WHEN** владелец прислал `bye` в `car/rt-link`
- **THEN** поток остановлен на ближайшем такте, не дожидаясь `video.subscribe_timeout_ms`

#### Scenario: Вытеснение
- **WHEN** при живом потоке сессию забрал другой пульт с новым sid
- **THEN** поток остановлен на ближайшем такте, прежнему адресату чанки больше не уходят; первый `view` нового владельца открывает поток заново, с ключевого кадра

#### Scenario: Граница тайм-аута
- **WHEN** с последнего принятого `view` прошло ровно `video.subscribe_timeout_ms`
- **THEN** подписка ещё жива; на миллисекунду позже — завершена
