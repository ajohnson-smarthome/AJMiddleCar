# Spec Delta

## MODIFIED Requirements

### Requirement: Сохранение — вся таблица одним запросом
После четвёртого назначения мастер SHALL показывать «Готово» с кнопкой «Сохранить»; до этого момента `POST` `endpoints.calibration` SHALL NOT посылаться — частичной таблицы не бывает. Тело SHALL быть объектом ровно с ключом `wheels` и четырьмя записями ровно с ключами `corner`, `pair`, `inverted`, углы названы именами из `calibration.corners` (на схеме колесо зовётся FL/FR/RL/RR, на проводе — `front_left`/`front_right`/`rear_left`/`rear_right`) в порядке `calibration.corners`. Пока ответ в пути, мастер показывает «Сохранение…» без кнопок. Принятым сохранение SHALL считаться только по `200`, чьё тело читается как таблица `endpoints.calibration`; содержимое ответа с отправленным не сверяется — правда о таблице остаётся за машинкой. По принятому сохранению мастер SHALL закрываться сам, по факту принятого ответа, а не по кадру телеметрии: открытый из настроек — обратно в настройки; обязательный — лист закрывается целиком, сразу на экран вождения, без промежуточного возврата на второй шаг, и кадр телеметрии с `motors.calibrated:false`, посчитанный машинкой до записи, его заново не открывает (`«Два входа…»`).

#### Scenario: Сохранить
- **WHEN** человек нажимает «Сохранить»
- **THEN** машинке уходит один `POST` `endpoints.calibration` с четырьмя записями в порядке `calibration.corners`, у каждой ровно `corner`, `pair`, `inverted`

#### Scenario: Принято
- **WHEN** машинка отвечает `200` с таблицей
- **THEN** мастер закрывается, других запросов не уходит

#### Scenario: Принято в обязательном мастере
- **WHEN** обязательный мастер получил `200` на сохранение, а следующий кадр телеметрии ещё не пришёл
- **THEN** лист закрыт, показан экран вождения; «Параметры колёс, шаг 2 из 3» не появляется, и кадр с `calibrated:false`, пришедший следом, мастер не открывает

#### Scenario: Ответ не читается
- **WHEN** машинка отвечает `200`, но тело не разбирается как таблица
- **THEN** сохранение считается неудавшимся
