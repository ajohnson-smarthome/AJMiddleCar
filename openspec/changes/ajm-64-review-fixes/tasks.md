# Tasks

Пункт — один воркер, один набор файлов, один PR; issues в скобках — что закрывает (`Closes` каждого в PR). Общая проверка: тест, падающий до починки, в хост-наборе; поведение после починки совпадает с дельтой в `specs/<capability>/spec.md` — если дельты нет, воркер пишет `MODIFIED` с полным блоком требования (валидатор требует все прежние сценарии); `openspec validate ajm-64-review-fixes --strict`; `CONFORMANCE=required tools/test-all.sh`; для пунктов приложения — `xcodebuild` под симулятор и прогон против мока. Исходные issues — источник `file:line` и «направления починки»; трассы — `openspec/changes/archive/2026-09-19-ajm-64-logic-review/review/`. Пункты `(стенд)` — человеку с платой; issues, которые они подтверждают, остаются In Review до них.
