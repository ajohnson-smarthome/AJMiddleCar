# Proposal

## Why

Логическое ревью (`ajm-64-logic-review`, 2026-09-19) оставило 44 находки, из них 8 `high`; триаж (`review/00-triage.md`) свёл их к трём швам, каждый найден двумя путешествиями независимо: адаптер сдаётся первым и его никто не переспрашивает; принудительное обновление не умеет второй попытки; повтор подъёма плат ШИМ не чистит шину. Плюс геймпад рулит под модальным листом и опрос ленты выпусков блокирует адрес GitHub на час. Это третий change эпика `AJM-64`: всё, что в коде продукта — прошивка машинки, адаптера, пульт, `release.sh`. Мок и conformance — параллельный `ajm-64-mock-parity`.

Пять находок — решения, не баги; принятые пользователем 2026-09-19 дефолты:
`AJM-107` — пауза телеметрии не сносит листы; `AJM-93/100` — импульс при `bus: down` → `409 busy`, мастер показывает «драйвер не отвечает» и закрывается; `AJM-97` — бюджет доставки радио сбрасывается при смене `radio.expected`; `AJM-129` — потолок `recovery.window_ms` в контракте 8 000; `AJM-116` — флаги деградации мока (в `mock-parity`).

## What Changes

**Прошивка машинки.** Повтор подъёма плат чистит шину и ставит тени «неизвестно» (`AJM-127`, `91`), обнуление выходов до `init` (`128`), импульс калибровки вне разгона (`109`); `spin` при `bus: down` → `409` (`100`); бюджет радио по версии (`97`), результат `mark_app_valid` читается (`138`); записи `wheel`/`chassis` разбираются по полям (`104`); сенсор, умерший на ходу → `video.state: off` (`94`); потолок `recovery.window_ms` 8 000 и `CONFIG_ESP_TASK_WDT_TIMEOUT_S` в `sdkconfig.defaults` (`129`, `130`).

**Адаптер.** Uplink считает тишину временем, а не пакетами, и на TCP-пути тоже (`124`, `96`); `POST /ota` возвращает конверт, не `ESP_FAIL` (`137`).

**Пульт.** Страж на затянувшийся поиск после гейта → перезапуск со ступени машинки (`95`, `125`, `134`); потерянный `POST /wifi` — не «не удалось подключиться» (`126`); лента выпусков реже плат и с чтением 403/429 (`136`); принудительный экран: «Повторить» → автозагрузка (`123`, `131`), точка отсчёта отката — последняя залитая сборка (`132`), заливка после сверки версии (`135`), `radio.state` виден (`92`); лист поверх экрана вождения обнуляет намерение и глушит геймпад (`101`), «поиск» — поверх, не вместо (`107`), домен `video` первым (`114`, `115`), кнопка видео повторяет чтение (`120`), битрейт вступает в силу (`122`), мастер закрывается по сохранению (`102`), при `bus: down` — сообщение и выход (`93`); `reset_at_boot` сбрасывает кэш с уведомлением (`99`); запись доменов по действию, редуктор по завершению ввода (`106`, `112`).

**Сквозное.** `release.sh`: черновик → файлы → публикация (`139`). Спека `car/actuator-arbiter`: слово в сценарии «Сторож раньше срока» (`98`).

**Не входит.** Трюки (`AJM-60/61/62`); мок и conformance (`AJM-86`, `103–121` кроме уже названных) — `ajm-64-mock-parity`.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `car/actuator-arbiter`: подъём плат чистит шину, `bus` честен без команды, импульс калибровки вне разгона, слово сценария.
- `car/calibration`: импульс при `bus: down` — `409 busy`.
- `car/radio-and-network`: бюджет доставки — на версию, не навсегда.
- `car/video-stream`: сенсор, умерший на ходу, — `off`, повторы реже.
- `car/config`: запись домена читается по полям.
- `car/rt-link`: который бюджет старше — простой сессии или окно возврата.
- `dongle/car-join`: серия uplink — по времени, на обоих путях.
- `dongle/api`: отказ `/ota` — конвертом до конца.
- `app/launch-ladder`: страж поиска, потерянный `POST /wifi`, темп опроса ленты, точка отсчёта отката.
- `app/firmware-update`: автозагрузка после «Повторить», сверка перед заливкой, радио на экране.
- `app/drive-session`: лист поверх — намерение ноль, «поиск» поверх экрана.
- `app/drive-hud`: `video` первым, кнопка как повтор чтения, битрейт вступает в силу.
- `app/calibration`: закрытие по сохранению, `bus: down`.
- `app/settings`: `reset_at_boot`, запись по действию, редуктор по завершению.
- `shared/release`: публикация после файлов.

## Impact

- Код всех трёх компонентов и `tools/release.sh`; контракт — только диапазон `recovery.window_ms` (генератор, `proto` не растёт); `sdkconfig.defaults`.
- Спеки — дельты `MODIFIED` выше; при propose написаны те, что несут решения, остальные дописывает воркер своего пункта (форма — валидатор).
- Стенд: три подтверждения после слияния (SDA/RESET, хронометраж OTA, `bus: down` в мастере) — `review/00-bench.md` § 0; issues `AJM-127/91/128/124/96` остаются In Review до них.
- Linear: dev-задачи — в проект эпика; каждая закрывает свои issues строками `Closes`.
