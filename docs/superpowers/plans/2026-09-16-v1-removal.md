# Снятие мостиков v1 — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** из приложения уходит всё, что понимало формат v1: декодер `LegacyIdentity`, ветка
`.legacy` в `DongleReply`/`DongleLink`, зонд `/status` в `CarLink` и всё, что от него
питалось; формат один, без «v1/v2».

**Architecture:** чистое удаление в четыре шага, каждый оставляет приложение собирающимся.
Сначала адаптерная половина (`DongleLink` + лестница в `AppFlow`) — там единственный новый
тест: v1-тело декодируется как `.faulty`. Потом машинная половина (зонд в `CarLink`,
`carProbed`, `carReachable`, `FirmwareFlow.forCar`). Потом последний потребитель
`LegacyIdentity` (`DongleState.refresh`) переводится на `DongleReply.decode`, и файл с
тестом удаляются. В конце — документы и проверка `grep`-ом.

**Tech Stack:** Swift/SwiftUI (host-тесты `swiftc` через `tools/test-all.sh`, сборка
`xcodebuild` под симулятор); XcodeGen (проект генерируется из папки, `xcodegen generate`
после удаления файла); Python 3 (один комментарий в тесте мока).

**Spec:** `docs/superpowers/specs/2026-09-16-v1-removal-design.md`
